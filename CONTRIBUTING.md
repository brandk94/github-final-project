# Contributions

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

# Bug Reports

Any bugs that hinder the application's performance and/or functionality are to be reported to the Issues tab. Please describe in accurate details what the bug(s) is, when it started and in what commit, and if possible the file(s) where the bug is suspected to originate from. This way, it is better to catch and fix the bug(s).

# Documentation Improvements

The Wiki tab is open for everyone to suggest ideas and layouts to better enhance the project blueprint or make adjustments to the current workflow.

# Code of Conduct

Everyone is expected to follow a code of conduct for this project, including:
